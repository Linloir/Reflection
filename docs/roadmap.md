# 后续工作

以下是未完成工作的方向，不是已提供功能的承诺。

## 完成应用与设备验收

- 在 Windows 机器上运行 native tests、协议集成检查和 Windows Ink 应用验收。
- 为常用白板、绘画、笔记软件记录压力、倾斜、橡皮擦和侧键结果。
- 实际验证三端 RFCOMM，测量持续书写的尾部延迟和断连恢复。
- 增加 Tab10C Pro、其他 Android 版本、显示器缩放与多显示器矩阵。
- 对 Note2 异常倾斜建立可重复采集用例，避免针对一种固件猜测补偿。

## 更完整的系统输入后端

- 评估 Windows 虚拟 HID / VHF 驱动与 WinTab 兼容路线。
- 评估 macOS 虚拟 HID / DriverKit 路线及分发授权条件。
- 驱动需要明确的签名、安装、卸载、系统升级和故障回退策略。
- 当前 Quartz / Windows Ink 后端应继续可独立使用。

## 客户端与电子纸体验

- 在独立渲染接口中接入厂商快速墨迹，不让其影响协议和输入采集。
- 设计覆盖更多屏幕的可替换 UI、快捷键与映射配置界面。
- 增加可测量的队列年龄、采样频率和会话统计，避免只显示平均 RTT。
- 评估 USB 无 ADB 部署方式，保持无需 root 的安装流程。

## iPad

以原生 UIKit / Pencil 采集为起点，复用线协议和测试向量。
USB 和蓝牙分别设计，不能把 Android ADB / Classic RFCOMM 方案照搬。
详细边界见 [iOS 规划](../client/ios/README.md)。

## 开源发布

- 自动构建与测试、签名安装包、版本升级和配置迁移。
- 可选的加密网络传输以及更易操作的初次配对。
- 原生桌面 UI 复用现有控制库，并保持 CLI 功能等价。
